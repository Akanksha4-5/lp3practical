### **Basic questions**

**1. What is the aim of this practical?**

To predict whether a person has diabetes using the K-Nearest Neighbors classification algorithm.

**2. What is diabetes prediction?**

It is the process of using patient-related data to predict whether a person is likely to have diabetes.

**3. What is Machine Learning?**

Machine Learning is a branch of AI that allows computers to learn patterns from data and make predictions.

**4. What type of learning is used in this practical?**

Supervised learning because the dataset contains labelled outcomes.

**5. Is this classification or regression?**

Classification because the output has two classes: 0 and 1.

**6. What is the dataset name?**

`diabetes.csv`.

### **Dataset questions**

**7. What is the target column?**

`Outcome`.

**8. What does Outcome = 0 mean?**

The person does not have diabetes according to the dataset label.

**9. What does Outcome = 1 mean?**

The person has diabetes according to the dataset label.

**10. How many input features are used?**

Eight input features.

**11. Name the eight input features.**

Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction and Age.

**12. Why do we create a dataset copy?**

To make changes to the copied dataset without modifying the original dataset.

**13. Why are zero values replaced with NaN?**

Because zero is treated as an invalid or missing measurement in selected medical columns.

**14. What is NaN?**

NaN stands for Not a Number. It represents a missing or undefined value.

**15. What is the difference between mean and median?**

Mean is the average, whereas median is the middle value after sorting the data.

**16. Why do we use mean for Glucose and BloodPressure?**

To fill missing values using the average of the available measurements.

**17. Why do we use median for Insulin, BMI and SkinThickness?**

To fill missing values using the middle value, which is less affected by extreme values.

### **KNN questions**

**18. What is KNN?**

KNN stands for K-Nearest Neighbors. It classifies a new data point based on the majority class of its nearest neighbors.

**19. Is KNN supervised or unsupervised?**

KNN is a supervised learning algorithm.

**20. What is K in KNN?**

K represents the number of nearest neighbors considered for prediction.

**21. Which K values are tested in our practical?**

K values from 1 to 14.

**22. Which K value is used in the final model?**

K = 11.

**23. Why do we use K = 11?**

The practical creates the final model using 11 neighbors. The code tests K values first, but it does not automatically select the best K; the testing scores should be checked before choosing it.

**24. What happens if K is too small?**

The model may become sensitive to noise and overfit.

**25. What happens if K is too large?**

The model may become too generalized and underfit.

**26. How does KNN calculate distance?**

It commonly uses Euclidean distance to measure the distance between data points.

**27. Why is KNN called a lazy learner?**

Because it does not build a complex model during training. It stores training data and performs distance calculations during prediction.

### **Data preprocessing questions**

**28. Why do we use StandardScaler?**

To bring all numerical features to a similar scale.

**29. Why is scaling important in KNN?**

Because KNN uses distance calculations, and larger-valued features can dominate without scaling.

**30. What is train_test_split?**

It divides the dataset into training and testing data.

**31. What is the train-test ratio in our practical?**

Approximately 66.67% training and 33.33% testing.

**32. What is stratify=y?**

It maintains the same approximate proportion of output classes in training and testing datasets.

**33. What is random_state=42?**

It makes the random splitting process reproducible.

### **Visualization and evaluation questions**

**35. What is a heatmap?**

A heatmap represents data values using different colors.

**36. What is a correlation matrix?**

**37. What is a decision boundary?**

A decision boundary separates different predicted classes.

**38. What is accuracy?**

Accuracy is the percentage of correctly predicted results out of all predictions.

**39. What is training accuracy?**

Accuracy calculated using the data used to train the model.

**40. What is testing accuracy?**

Accuracy calculated using unseen testing data.

**41. Why do we compare training and testing accuracy?**

To understand how well the model learns and how well it performs on unseen data.

**42. What is&#x20;**`plot_decision_regions()`**?**
