# ML3 - Bank Customer Churn Prediction using Neural Network

# Importing libraries
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# Loading dataset
df = pd.read_csv("Churn_Modelling.csv")

df.head()
df.shape
df.describe()
df.isnull()
df.isnull().sum()
df.info()
df.dtypes
df.columns

# Dropping unnecessary columns
df = df.drop(['RowNumber', 'Surname', 'CustomerId'], axis=1)

df.head()

# Visualization function
def visualization(x, y, xlabel):
    plt.figure(figsize=(10, 5))
    plt.hist([x, y], color=['red', 'green'],
             label=['exit', 'not_exit'])
    plt.xlabel(xlabel, fontsize=20)
    plt.ylabel("No. of customers", fontsize=20)
    plt.legend()

# Visualization of Tenure
df_churn_exited = df[df['Exited'] == 1]['Tenure']
df_churn_not_exited = df[df['Exited'] == 0]['Tenure']

visualization(df_churn_exited, df_churn_not_exited, "Tenure")

# Visualization of Age
df_churn_exited2 = df[df['Exited'] == 1]['Age']
df_churn_not_exited2 = df[df['Exited'] == 0]['Age']

visualization(df_churn_exited2, df_churn_not_exited2, "Age")

# Encoding categorical variables
states = pd.get_dummies(df['Geography'], drop_first=True, dtype=int)
gender = pd.get_dummies(df['Gender'], drop_first=True, dtype=int)

df = pd.concat([df, gender, states], axis=1)

df.head()

# Selecting input and output variables
X = df[['CreditScore', 'Age', 'Tenure', 'Balance',
        'NumOfProducts', 'HasCrCard', 'IsActiveMember',
        'EstimatedSalary', 'Male', 'Germany', 'Spain']]

y = df['Exited']

# Splitting dataset
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, random_state=42
)

# Feature scaling
from sklearn.preprocessing import StandardScaler

sc = StandardScaler()

X_train = sc.fit_transform(X_train)
X_test = sc.transform(X_test)

# Importing Keras
import keras
from keras.models import Sequential
from keras.layers import Dense

# Creating ANN model
classifier = Sequential()

# Adding input and hidden layer
classifier.add(Dense(
    activation="relu",
    input_dim=11,
    units=6,
    kernel_initializer="uniform"
))

# Adding second hidden layer
classifier.add(Dense(
    activation="relu",
    units=6,
    kernel_initializer="uniform"
))

# Adding output layer
classifier.add(Dense(
    activation="sigmoid",
    units=1,
    kernel_initializer="uniform"
))

# Compiling the model
classifier.compile(
    optimizer="adam",
    loss="binary_crossentropy",
    metrics=['accuracy']
)

# Displaying model summary
classifier.summary()

# Training the ANN model
classifier.fit(
    X_train,
    y_train,
    batch_size=10,
    epochs=50
)

# Predicting test data
y_pred = classifier.predict(X_test)

# Converting probabilities into 0 or 1
y_pred = (y_pred > 0.5)

# Evaluating model
from sklearn.metrics import confusion_matrix, accuracy_score, classification_report

cm = confusion_matrix(y_test, y_pred)

cm

# Calculating accuracy
accuracy = accuracy_score(y_test, y_pred)

accuracy

# Plotting confusion matrix
plt.figure(figsize=(10, 7))

sns.heatmap(cm, annot=True)

plt.xlabel('Predicted')
plt.ylabel('Truth')

# Classification report
print(classification_report(y_test, y_pred))

classifier = Sequential()

- epochs=50: The model goes through the complete training dataset 50 times.

Predicts the probability of customers leaving the bank.

Converts probabilities into binary output:
- Greater than 0.5 = True / 1 (Exited).

Basic questions
1. What is customer churn?

Customer churn means when a customer stops using the services of a company or bank.

2. What is the aim of this practical?

To predict whether a bank customer will leave or stay using an Artificial Neural Network.

3. What is ANN?

ANN stands for Artificial Neural Network. It is a machine learning model inspired by the working of the human brain.

4. What is Keras?

Keras is a deep learning API used to build and train neural networks. In this practical, it is used with TensorFlow.

5. What is TensorFlow?

TensorFlow is an open-source machine learning framework used to build and train machine learning and deep learning models.

6. What type of learning is used here?

Supervised learning because the dataset contains labelled output in the Exited column.

7. Is this classification or regression?

Classification because the output is divided into two classes: 0 and 1.

Churn_Modelling.csv

Exited.

The customer has not left the bank.

Neural network questions
15. What is a neuron?

A neuron is a basic unit of an artificial neural network that processes input and produces output.

16. What is a Dense layer?

A Dense layer is a fully connected layer where each neuron is connected to all neurons in the previous layer.

17. What is the Sequential model?

It is a Keras model used to create neural networks by adding layers one after another.

11 input features.

2 hidden layers.

6 neurons in each hidden layer.

21. How many neurons are there in the output layer?

1 neuron.

22. What is ReLU?

ReLU stands for Rectified Linear Unit. It is an activation function used in hidden layers.

23. What is Sigmoid?

Sigmoid is an activation function that produces an output between 0 and 1.

24. Why is sigmoid used in the output layer?

Because this is a binary classification problem and sigmoid gives a probability for the two classes.

25. What is an activation function?

An activation function decides the output of a neuron and helps the network learn complex patterns.

28. What is batch size?

29. What is the batch size in our practical?

30. What is Adam optimizer?

The percentage of correct predictions made by the model.

34. What is a confusion matrix?

A table that compares actual values with predicted values.

Precision tells us how many predicted positive results are actually positive.

36. What is recall?

Recall tells us how many actual positive cases are correctly identified.

37. What is F1-score?

F1-score is the harmonic mean of precision and recall.

Precision, recall, F1-score and support for each class.

Training data teaches the model, while testing data checks how well the model performs on unseen data.
