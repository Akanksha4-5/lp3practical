# ML2 - Email Spam Detection (KNN vs SVM)

# Importing libraries
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

%matplotlib inline

import warnings
warnings.filterwarnings('ignore')

from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
from sklearn import metrics


# Loading the dataset
df = pd.read_csv('emails.csv')

df.head()

# Displaying column names
df.columns

# Checking missing values
df.isnull().sum()

# Removing missing values
df.dropna(inplace=True)

# Removing unnecessary Email No. column
df.drop(['Email No.'], axis=1, inplace=True)


# Separating independent and dependent variables
X = df.drop(['Prediction'], axis=1)

y = df['Prediction']


# Feature scaling
from sklearn.preprocessing import scale

X = scale(X)


# Splitting dataset into training and testing data
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)


# KNN CLASSIFICATION

from sklearn.neighbors import KNeighborsClassifier

# Creating KNN model
knn = KNeighborsClassifier(n_neighbors=7)

# Training the model
knn.fit(X_train, y_train)

# Predicting the output
y_pred = knn.predict(X_test)

# Displaying predictions
print("Prediction", y_pred)

# Calculating KNN accuracy
print(
    "KNN accuracy = ",
    metrics.accuracy_score(y_test, y_pred)
)

# Confusion matrix
print(
    "Confusion matrix",
    metrics.confusion_matrix(y_test, y_pred)
)


# SVM CLASSIFICATION

# Creating SVM model with cost C = 1
model = SVC(C=1)

# Training the model
model.fit(X_train, y_train)

# Predicting the output
y_pred = model.predict(X_test)

# Displaying confusion matrix
print(
    metrics.confusion_matrix(
        y_true=y_test,
        y_pred=y_pred
    )
)

# Calculating SVM accuracy
print(
    "SVM accuracy = ",
    metrics.accuracy_score(y_test, y_pred)
)

### **Step 13: Create SVM model**

```
from sklearn.svm import SVCmodel = SVC(C=1)
```

SVM stands for **Support Vector Machine**.

It is a supervised machine learning algorithm used for classification.

It finds the best decision boundary, called a **hyperplane**, to separate different classes.

`C=1` is the regularization parameter. It controls the balance between classification errors and a wider margin.

### **Step 14: Train SVM model**

```
model.fit(X_train, y_train)
```

Trains the SVM model using training data.

### **Step 15: Predict output**

y_pred = model.predict(X_test)
```

Predicts whether each test email is spam or not spam.

### **Step 16: Display confusion matrix**

```
metrics.confusion_matrix(    y_true=y_test,    y_pred=y_pred)

## **4. Difference between KNN and SVM**

| KNN                                        | SVM                                       |
| ------------------------------------------ | ----------------------------------------- |
| K-Nearest Neighbors                        | Support Vector Machine                    |
| Distance-based algorithm                   | Hyperplane-based algorithm                |
| Uses nearest neighbors                     | Finds the best decision boundary          |
| `k` decides the number of neighbors        | `C` controls regularization               |
| Simple to understand                       | Can handle complex decision boundaries    |
| Prediction can be slower on large datasets | Training can be computationally expensive |

## **5. Important viva questions and answers**

### **Basic machine learning questions**

**1. What is Machine Learning?**

Machine Learning is a branch of AI that allows computers to learn from data and make predictions without being explicitly programmed for every task.

**2. What is classification?**

Classification is a supervised learning technique used to divide data into predefined categories.

**3. What is email spam detection?**

It is the process of identifying unwanted or promotional emails and separating them from genuine emails.

**4. What is supervised learning?**

Supervised learning is a type of machine learning in which the model is trained using labelled data.

**5. What is a dataset?**

A dataset is a collection of data used to train and test a machine learning model.

**6. What is the target variable?**

The target variable is the output that the model tries to predict. In our practical, it is `Prediction`.

**7. What are features?**

Features are the input variables used by the model to make predictions. In our practical, they are the email-related columns other than `Prediction`.

### **KNN viva questions**

**8. What is KNN?**

KNN stands for K-Nearest Neighbors. It classifies a data point based on the majority class among its nearest neighbors.

**9. What is K in KNN?**

K is the number of nearest neighbors considered for classification.

**10. What is the value of K in our practical?**

The value of K is 7.

**11. Why do we use KNN?**

We use KNN to classify emails into spam and not spam based on similarities with nearby examples.

**12. Is KNN supervised or unsupervised?**

KNN is a supervised learning algorithm.

**13. What happens if K is too small?**

The model may become sensitive to noise and overfit.

**14. What happens if K is too large?**

The model may become too generalized and underfit.

### **SVM viva questions**

**15. What is SVM?**

SVM stands for Support Vector Machine. It is a supervised learning algorithm used mainly for classification.

**16. What is a hyperplane?**

A hyperplane is a decision boundary that separates different classes.

**17. What are support vectors?**

Support vectors are the data points closest to the decision boundary. They help determine the position of the hyperplane.

**18. What is the use of C in SVM?**

C is a regularization parameter that controls the trade-off between classification errors and margin size.

**19. What is the value of C in our practical?**

The value of C is 1.

**20. What is the difference between SVM and KNN?**

KNN classifies using the nearest neighbors, whereas SVM classifies using an optimal decision boundary.

### **Dataset and evaluation questions**

**21. What is&#x20;**`train_test_split()`**?**

It divides the dataset into training and testing data.

**22. Why do we use 70:30 splitting?**

70% data is used for training and 30% is used for testing the model.

**23. What is&#x20;**`random_state=42`**?**

It ensures reproducibility by keeping the random split consistent.

**24. What is feature scaling?**

Feature scaling brings numerical features to a similar scale.

**25. Why is scaling important in KNN and SVM?**

Because both algorithms can be affected by differences in feature magnitudes.

**26. What is accuracy?**

Accuracy is the percentage of correctly predicted results out of all predictions.

**27. What is a confusion matrix?**

It is a table that shows correct and incorrect predictions made by a classification model.

**28. What is overfitting?**

Overfitting happens when a model performs well on training data but poorly on new data.

**29. What is underfitting?**

Underfitting happens when a model fails to learn the patterns in the training data properly.

**30. Which algorithm is better, KNN or SVM?**

The algorithm with higher testing accuracy performs better on this dataset. We should compare their results rather than assume one is always better.
